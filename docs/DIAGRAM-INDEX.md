# ApexStay ERP — Module 04 Diagram Pack

All diagrams below describe the current Module 04 implementation. They intentionally do not claim to describe the other six modules. Integration actors are shown as external systems until the group confirms their shared interfaces and database contracts.

## Render the diagrams

1. Install the PlantUML extension in VS Code, or install PlantUML with Graphviz.
2. Open any `.puml` file in `docs/diagrams/`.
3. Use **PlantUML: Preview Current Diagram**. Export PNG/SVG for the final paper.
4. Keep `.puml` source files with the project so diagrams remain editable.
